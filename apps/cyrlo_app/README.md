# Cyrlo Ride (Flutter)

One app for **passengers** and **riders**. Phone + OTP auth (no password). Yellow / dark grey brand; dark theme by default.

Progress and feature notes: [`docs/FLUTTER_APP_UI_PROGRESS.md`](../../docs/FLUTTER_APP_UI_PROGRESS.md)
